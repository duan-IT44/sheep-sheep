# 任务管理系统

## 项目简介

面向企业内部的任务分配与管理系统，支持管理员分配任务、员工查看并更新任务状态。

## 技术栈

- 后端：Python Flask
- 数据库：SQLite
- 前端：HTML + Vue3 + Element Plus（CDN）

## 功能列表

- 用户登录与角色权限
- 任务增删改查
- 任务分配与状态更新
- 员工管理
- 数据统计

## 运行方式

1. 安装依赖：`pip install flask flask-cors`
2. 启动服务：`python app.py`
3. 浏览器访问：`http://localhost:8080`
